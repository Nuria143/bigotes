# Mustache Enthusiast
**Mustache Enthusiast** es una plantilla web sobre bigotes,
desarrollada con *HYML, CSS y Java Script*.

## Archivos y uso
- `index.hmtl`: página principal.
- about.html: página de información.

Para utilizarla:
1. Descarga o clona el proyecto.
2. Abre la página principal en el navegador.

Para clonarlo:
```bash
git clone https://github.com/Nuria143/bigotes.git
```
